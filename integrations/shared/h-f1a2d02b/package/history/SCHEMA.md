# Shared immutable ledger v1
records.json contains all requested keys. Null means unknown; zero is a measured zero only. source_locator uses sheet/cell or UID/field, or a stable extracted conversation message_key. No unsupported PDF cell allocation has been fabricated. Raw PDFs and daily ZIP are bundled for future reconciliation.
project_id uses the user's scope IDs, building_id is separate, contract_id nullable; see identity-registry.json. system/phase/face are exact native labels where available; do not silently canonicalize them without a reviewed dictionary.
status distinguishes observed, source_conflict, native_verified, derived_partial_coverage, missing, superseded. decision.kind separates user_explicit, user_qualified and calculation. Statement D-STAFF is a summary, not an exact verbatim quote. Timestamps absent in chat exports are null. supersedes links previous records, never erases them. For revised observations preserve both raw and normalized facts with derived_from. A frozen release must pin sources' SHA256, decisions, mappings and accepted record IDs; changing one creates a new freeze/version.
This is a verified MSP-scope ledger plus selected staffing/delivery gaps, NOT a claim to complete extraction of every historical source/PDF. Employer cell inventory supplies exact whole-workbook lineage; shared schema completion for all daily/material records remains coordinator work.
