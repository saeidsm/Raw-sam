OutlineCode1 پیمانکار،۲ فاز،۳ سیستم/مصالح،۴ ساختمان،۵ نما است.

فرمول‌های واقعی در `native-fields.json` آمده‌اند. Number5 مقدار تجمعی قابل نوشتن؛ Number9 حجم کل ثابت.
